# Vorsorgeheft

Vorsorgetermine für die ganze Familie: U-Untersuchungen, STIKO-Impfungen,
Zahnvorsorge und Erwachsenen-Früherkennung, berechnet aus dem Geburtsdatum.
Alles bleibt auf dem Telefon, ohne Konto und ohne Server.

Telefon.
